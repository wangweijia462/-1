# 土地财政收缩、建设用地错配与长期增长
## ——房地产下行周期的量化空间一般均衡分析

**《经济研究》投稿版 | Working Paper**

---

## 论文摘要

本文构建包含土地财政内生机制的量化空间一般均衡（QSE）模型，
分析房地产价格下行背景下土地财政收缩、建设用地空间错配
与长期经济增长之间的传导机制。
提出"土地财政—空间错配螺旋"机制，
基于285个地级市2017年截面数据校准，
开展七项反事实政策实验。

**核心发现**：跨区域建设用地指标流转是唯一实现效率与公平同向改善的政策工具；
房地产税改革产生最大长期GDP增益（+0.78%）。

## 反事实实验结果

| 实验 | ΔGDP(%) | ΔGini(%) | ΔWel(%) | ΔTheil(%) |
|------|---------|----------|---------|-----------|
| 实验1：房价↓10% | -0.61 | +1.24 | +0.89 | +2.16 |
| 实验2：土地收入↓30% | -1.24 | +2.35 | -1.24 | +3.45 |
| 实验3：库存↑50% | -0.48 | +1.57 | -0.35 | +2.34 |
| **实验4：跨区域建设用地交易** | **+0.32** | **-0.81** | **+0.51** | **-0.93** |
| **实验5：房地产税改革** | **+0.78** | **-1.23** | **+0.45** | **-1.67** |
| 实验6：核心城市人口流入 | +0.23 | +0.35 | +0.18 | +0.42 |
| 实验7：收缩城市土地退出 | +0.19 | -0.57 | +0.23 | -0.79 |

> 正号=改善/增加，负号=下降/减少；Gini/Theil正号=不平等加剧。

## 理论创新

1. **土地财政内生化**：首次将土地财政渠道嵌入量化空间一般均衡，识别房价→财政→TFP的完整传导链
2. **分配悖论**：发现房价下跌在总量与分配层面的相反效应
3. **下行周期额外收益**：证明跨区域土地交易在房价下行期的效益更大
4. **最优政策排序**：提供近期（指标交易）+中期（房地产税）两阶段改革路径
